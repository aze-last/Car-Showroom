# Design Tokens & Styling Reference

## Color Palette (Premium White System)

| Token Name | Color Hex / Utility | Use Case |
| :--- | :--- | :--- |
| **Primary Background** | `#ffffff` (`bg-white`) | Card containers, modal bodies, top headers |
| **Surface Secondary** | `#fafafa` (`bg-zinc-50`) | Card backgrounds, table headers, form inputs |
| **Borders** | `border-zinc-200/80` / `border-zinc-100` | Subtle container demarcations |
| **Primary Typography** | `#18181b` (`text-zinc-900` / `text-black`) | Headings, primary metrics, labels |
| **Subtle Typography** | `#a1a1aa` (`text-zinc-400`) | Subtitles, uppercase tracking labels |
| **Available Accent** | `#10b981` (`bg-emerald-500` / `text-emerald-700`) | Active inventory, approved deposits |
| **Sold / Neutral Accent** | `#18181b` (`bg-zinc-900` / `text-zinc-900`) | Sold vehicles, primary CTAs |
| **Pending Accent** | `#f59e0b` (`bg-amber-500` / `text-amber-700`) | Pending deposits, auction candidate warnings |
| **Danger Accent** | `#dc2626` (`bg-red-600` / `text-red-700`) | Blocked collectors, soft deletion actions |

## Typography Scale

- **H1 / Main Titles**: `text-3xl font-bold tracking-tight text-zinc-900`
- **H2 / Section Titles**: `text-xl font-bold tracking-tight text-zinc-900`
- **Section Labels**: `text-[11px] font-bold uppercase tracking-widest text-zinc-400`
- **Body Text**: `text-xs font-normal text-zinc-600`
- **Data KPI Values**: `text-3xl font-extrabold tracking-tight text-zinc-900`

## Corner Radii

- **Cards & Containers**: `rounded-3xl`
- **Modals & Drawers**: `rounded-3xl` / `rounded-[40px]`
- **Inputs & Buttons**: `rounded-xl`
- **Badges & Pills**: `rounded-full`
